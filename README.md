### ⚡ How to Publish in 2 Minutes (Direct Web Upload - No Tools Needed)

If you don't have Git CLI installed:
1. Log in to [GitHub.com](https://github.com/) with account **`Thiloka-006`**.
2. Click **`+`** (top right) -> **New repository**.
3. Name your repository `portfolio` (or `Thiloka-006.github.io`).
4. Set visibility to **Public** and click **Create repository**.
5. Click **"uploading an existing file"**.
6. Select and drag all files inside your `Portfolio` folder (`index.html`, `css/`, `js/`, `assets/`, `README.md`) into GitHub.
7. Click **Commit changes**.
8. Go to **Settings** > **Pages** (left sidebar) -> Select `main` branch and `/ (root)` folder -> Click **Save**.

🎉 **Your Website is Live!**
